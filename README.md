# proyecto-tercerparcial
Sistema de Control de Citas en un Hospital

1. Datos del Trabajador
- Nombre completo
- Cargo (médico, enfermería, etc.)
- Fecha de ingreso
- Especialidad o área de trabajo

2. Administrar personal
   - tabla donde se podran guardas todos los datos de cada personal guardado
   -  se podra eliminar o editar la informacion del personal


3. Registro de pacientes
- Informacio del paciente como:
           -  nombre
           - edad
           -   No. seguuro social
           -   area asignada : Medicina General, Urgencias o Hospitalizacion
           -   docotor asignado
           -   enfermero asignado
  - asignarle una camilla 

4. Estado de camillas y asignacion
   - se asignara una camila y doctor cuando el paciente sea registrado
   - se podra liberar una camilla cunado un paciente este seleccionado para ser dato de alta
